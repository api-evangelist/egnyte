# Egnyte GraphQL API

Egnyte is a cloud content platform for business. The API covers file and folder management, sharing permissions, link creation, search, version history, audit logs, user provisioning, and project workspace management.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Egnyte REST API
**Documentation:** https://developers.egnyte.com/docs

- Reference: https://developers.egnyte.com/docs/read/File_System_Management_API_Documentation
- Schema: https://github.com/api-evangelist/egnyte
